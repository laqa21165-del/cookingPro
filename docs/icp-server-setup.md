# ICP 备案 + 云服务器 具体操作步骤（mylove 文字点单 · 阿里云视角）

> 本文给你「可以照做」的步骤。以 **阿里云** 为例（你的服务器在阿里云华东1 杭州）。
> 平台界面会变，但大步骤稳定。所有"天"为自然日，管局审核以实际为准。

---

## ⚠️ 先分清：你要做两件不同的"备案"（在两个地方）

| 备案 | 在哪做 | 备案类型 | 为什么必须做 | 耗时 |
|---|---|---|---|---|
| **域名 ICP 备案** | 阿里云备案系统（因服务器在阿里云） | **网站**（阿里云无"微信小程序"备案类型；纯后端 API 域名归网站类） | 你的 `api/oss.yourdomain.com` 指向国内服务器，按法规域名必须 ICP 备案 | 1–2 周 |
| **微信小程序备案** | 微信公众平台「设置 → 小程序备案」 | 小程序 | 2023.9 起**强制**：小程序不备案不能上架/提审 | 1–20 天 |

> 两件都要做，且**备案主体必须和小程序注册主体 100% 一致**（差一个字都被退）。
> 这两件事相互独立，可以**并行**推进，不互相阻塞。

> 主体建议：本小程序有"下单/订单"，若涉及经营属性，个人备案会被限（个人类只能"工具"类型、不能有经营）。若要稳妥 + 做"发给厨师"转发（需微信认证），**建议用企业/个体户主体**备案。

---

## 第一部分：买云服务器（≈10 分钟）

1. 打开 `aliyun.com` → 登录（账号先做**实名认证**）。
2. 进入 **云服务器 ECS** 或 **轻量应用服务器**（轻量更便宜好用，适合这种单后端场景）。
3. 配置：
   - **地域**：选**中国大陆**，你已选 **华东1（杭州）**。❗境外服务器不能备案、也不能给大陆备案域名用。
   - **镜像**：系统镜像 → `Ubuntu 22.04 LTS`（或 24.04 均可）。
   - **规格**：`2 核 2G` 起步（2G 需调优 PostgreSQL + 开 swap，见 backend-public-deploy.md 2.3.1）；4G 更省心，内存给 PG+Redis+MinIO+API 绰绰有余。
   - **计费**：**包年包月，购买时长 ≥ 3 个月**（备案要求服务器是包年包月且≥3个月、有公网 IP）。
   - 公网带宽：固定带宽（如 200Mbps）或按量均可，能稳定对外访问即可。
4. 下单 → 设置 root 密码 → 拿到**公网 IP**（记为 `你的服务器IP`）。

---

## 第二部分：买域名 + 实名（≈30 分钟，之后还要等 3 天）

1. 阿里云 → **域名注册** → 搜你想要的（如 `yourdomain.com` / `.cn`）。
   - ❗ 别买 `.ai` 等不能备案的后缀。
2. 下单购买 → 进入**域名控制台** → 对域名做**实名认证**：
   - 所有者姓名/名称 **必须和你要备案的主体完全一致**（个人填自己姓名；企业填营业执照名称）。
3. ⚠️ **实名认证通过后，要等约 3 天**才会同步到工信部系统，之后才能提交备案。趁这 3 天去准备服务器和材料。

---

## 第三部分：域名 ICP 备案（阿里云，选「网站」类型，1–2 周）

### 前置
- 阿里云账号已实名；服务器已买（国内、包年包月≥3月）；域名已实名且过了 3 天同步期。

### 材料清单
- **个人备案**：身份证正反面（原件拍照，边角完整、无反光）；负责人手机号+邮箱。
- **企业备案**：营业执照副本；法人身份证；网站/服务负责人身份证（若负责人非法人，需**授权书**盖章）；负责人手机+邮箱。

### 步骤
1. 阿里云控制台 → 顶部「**备案**」→ `beian.aliyun.com` → 「我的备案」→ **新增备案**。
2. **选择备案类型：选「网站」**（不是 App，也不是小程序）。
   > ⚠️ 阿里云**不支持微信小程序备案类型**（仅支持淘宝小程序）。你的微信小程序备案在**微信公众平台**做（见第六部分）。这里备案的是**域名**，纯后端 API 域名在阿里云只能归「网站」类互联网信息服务。
3. **验证备案类型**：选「网站/域名」，填 `yourdomain.com`，选备案省份（与证件住址一致），「开始备案」。
4. **填主体信息**：姓名/证件号/通信地址，与证件 100% 一致。
5. **填互联网信息服务**：
   - 服务名称（网站）：别用"金融/彩票/视频"等敏感词；个人写"个人技术分享/工具"更易过。
   - 服务类型：**网站**。
   - 域名：`yourdomain.com`。
   - 服务内容：选"小程序"或对应的工具类；**备注说明"为微信小程序提供后端 API 服务，无独立网站"**，避免审核员疑惑。
   - 云资源：选你刚买的服务器（系统会自动生成备案服务号）。
   - 前置审批：没有就选"以上都不涉及"。
6. **服务负责人核验**：支付宝/钉钉扫页面二维码 → 上传身份证正反面原件 → **人脸识别/视频核身**。
7. **提交 → 阿里云初审（1–2 个工作日）**：保持手机畅通，可能来电核对信息。常见驳回：证件模糊、名称违规、信息不符。
8. **工信部短信核验（24 小时内！）**：初审过了，负责人手机会收到工信部短信（发往 `beian.miit.gov.cn`）→ 24 小时内登录工信部备案系统输验证码完成核验，**超时自动驳回**。
9. **管局审核（≤20 工作日）**：通过后会发备案号，格式如 `浙ICP备12345678号`。
10. **挂备案号**：网站/小程序"关于"页底部放备案号（并链接 `https://beian.miit.gov.cn`）。

> ⚠️ 首次备案期间，该域名**不能对外访问**（管局要求），等备案号下来再上线。

## 第四部分：域名解析到服务器

备案通过后（或同时，先把解析配好不影响备案）：
1. 阿里云 → **云解析 DNS** → 你的域名 → 「添加记录」：
   - `api`  → A 记录 → `你的服务器IP`
   - `oss`  → A 记录 → `你的服务器IP`
2. 等几分钟生效（`ping api.yourdomain.com` 看到服务器 IP 即对）。

## 第五部分：服务器初始化（装 Docker + Caddy）

SSH 登录服务器后执行：

```bash
# 1) 装 Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER   # 退出重登生效（或下面用 sudo）

# 2) 装 Caddy（自动 HTTPS）
sudo apt update
sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list
sudo apt update && sudo apt install -y caddy

# 3) 把代码传上来（git 克隆 或 scp -r apps/api）
# 4) 编辑 apps/api/docker-compose.yml 把所有 <请替换> / <你的域名> 换成真实值
# 5) 起后端
cd apps/api && sudo docker compose up -d --build

# 6) 编辑并加载 Caddyfile（把 <你的域名> 换成真实域名）
sudo caddy reload --config /path/to/Caddyfile
```

## 第六部分：微信小程序备案（公众平台，1–20 天）

> 这件事在**微信公众平台**做，**不在阿里云**。与第三部分的域名 ICP 备案相互独立，可并行推进。

1. 登录 `mp.weixin.qq.com` → 你的小程序 → 首页「**去备案**」（或 设置 → 小程序备案）。
2. **填主体信息**：个人填身份证；企业填营业执照（需在有效期）。主体必须 = 小程序注册主体。
3. **填小程序信息**：名称、简介、**服务类目**（工具类通常无需资质；电商/餐饮等需对应许可）。
4. **负责人人脸核身**：白底、五官无遮挡。
5. **微信平台初审（1–2 工作日）** → 站内信通知。
6. **工信部短信核验（24 小时内）**：收短信（12381）→ 去 `beian.miit.gov.cn` 验证。
7. **通管局审核（1–20 工作日）** → 下发**小程序备案号**。
8. 备案号下来后，才能在小程序后台「提交审核 → 发布」代码。

## 常见坑速查
- 域名实名后**等 3 天**才能备案，别急着提交。
- 工信部短信核验 **24 小时**超时即驳回，收到短信马上验。
- **个人备案不能做经营类**小程序；有交易属性建议企业主体。
- `.ai` 等后缀**不能备案**，选 `.com/.cn` 等。
- 备案主体、域名所有者、小程序主体三者必须**一致**。
- 首次备案期间域名不可访问，属正常。
- 服务器必须**包年包月且 ≥3 个月**，按量计费不能备案。
- ⚠️ 阿里云域名备案选**「网站」类型**；微信小程序备案在**公众平台**，不在阿里云。

## 时间线参考（理想情况）
买服务器+域名（当天）→ 域名实名等3天 → 阿里云域名ICP备案（~1周，选网站类型）→ 微信小程序备案（~1周，公众平台）→ 两者都下号后，配解析+部署+提交代码审核。建议**现在立刻启动备案**，这是最长链路。
